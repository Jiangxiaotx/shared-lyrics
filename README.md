# 共享歌词 · Shared Lyrics

> 把手机变成电脑版 QQ 音乐的**歌词屏 + 遥控器**。声音仍然从电脑的音箱 / 耳机出来，手机只负责显示与操作。

Windows 本地小服务，**零第三方依赖**（只用 Node.js 内置模块 + 系统自带的 PowerShell），不上传任何数据，关掉窗口即完全停止。

---

## 它能做什么

- **实时歌词**：读取 QQ 音乐当前播放的歌曲，自动匹配 LRC 逐行歌词并平滑滚动
- **歌词微调**：`-0.3s` / `+0.3s` 偏移，进度条拖动跳转（客户端不接受跳转时会提示并还原）
- **远程控制**：上一首 / 播放暂停 / 下一首，手机点一下电脑就响
- **真实封面**：QQ 音乐曲库封面优先，iTunes 兜底
- **全屏歌词**：双击空白或点右上角按钮，进入只剩歌词的沉浸模式
- **主题自定义**：字号、主题色、深色模式、背景模糊强度
- **横竖屏自适应**：竖屏上下排布，横屏左右分栏
- **局域网可用**：手机与电脑同一 Wi-Fi，无需注册、无需会员、不经过互联网

## 工作原理

```
手机浏览器  ⇄  server.js (Node, :8899)  ⇄  bridge.ps1 (PowerShell)  ⇄  Windows SMTC  ⇄  QQ 音乐
```

- `bridge.ps1` 通过 Windows 系统媒体传输控件（SMTC）读取播放状态与时轴，并下发播放控制指令；
- `server.js` 把状态整理成 HTTP 接口，同时托管手机端网页；
- 歌词优先取 LRCLIB，失败后回退 QQ 音乐歌词接口，最后读取本地 `lyrics/` 目录下的 `.lrc` 文件；
- 桥接进程带看门狗：6 秒无输出自动重启，桥接崩溃不会让整个服务挂掉。

## 快速开始

**环境**：Windows 10 / 11 + Node.js 18 以上（推荐 20+）+ 电脑版 QQ 音乐。

```bash
# 方式一：直接启动
双击 启动.bat

# 方式二：命令行
node server.js

# 方式三：npm
npm start
```

启动后黑窗口会打印：

```
==============================================
 共享歌词 已启动
 电脑本机：http://localhost:8899
 手机访问：http://192.168.x.x:8899
 保持本窗口开着；关闭窗口即停止服务
==============================================
```

手机连同一个 Wi-Fi，浏览器打开「手机访问」那一行地址即可。第一次启动记得在 Windows 防火墙弹窗里勾选**专用网络**并允许访问。

> 想改端口：`set PORT=9000 && node server.js`（PowerShell：`$env:PORT=9000; node server.js`）

## 文件结构

| 路径 | 说明 |
| --- | --- |
| `server.js` | HTTP 服务 + 歌词抓取 + 桥接进程管理 |
| `bridge.ps1` | PowerShell 桥接：读写 Windows 媒体会话 |
| `public/index.html` | 手机端页面（单文件，无构建、无 CDN） |
| `启动.bat` | Windows 一键启动脚本 |
| `保姆级教程.md` | 面向普通用户的全流程图文说明 |
| `cache/lyrics.json` | 歌词缓存（运行时生成，已忽略） |
| `lyrics/` | 可选：自备同名 `.lrc` 歌词目录（已忽略） |

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 当前播放状态（歌名 / 歌手 / 专辑 / 进度 / 时长） |
| POST | `/api/control` | 控制指令：`play` `pause` `toggle` `next` `prev` `seek` |
| GET | `/api/lyrics?title=&artist=&dur=` | 歌词（带缓存） |
| GET | `/api/cover?title=&artist=` | 专辑封面 |
| GET | `/api/health` | 健康检查 |
| GET | `/api/debug` | 桥接诊断信息 |

## 常见问题

见 [保姆级教程.md](./保姆级教程.md) 第 7 节：手机打不开、未检测到播放、歌词不对、进度条回弹、端口占用等。

## 隐私

- 只监听局域网，外网无法访问
- 不上传任何播放数据
- 联网仅用于：获取歌词、获取专辑封面
- 不写注册表、不装服务、不留后台进程
